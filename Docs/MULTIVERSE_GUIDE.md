# A FIELD PRIMER ON THREADS, RIFTS & CONVERGENCE
### (Quantum-Timeline Causality — Reader's Guide, Unclassified)

*An in-universe primer on how reality is structured in this setting. It explains
the **rules**, not the events — no plot, no names, no outcomes. Read it to
understand the board, not the game being played on it.*

---

## 1. THE THREAD

A **Thread** is one complete, self-consistent timeline: a universe running its own
unbroken chain of cause and effect from beginning to end. Inside a Thread,
causality is **local** — every effect has a cause *within the same Thread*.

```
   THREAD  ──●──●──●──●──●──●──●──▶   (time →)
            cause → effect → cause → effect …
```

Threads are normally **sealed**. Nothing inside one can see, touch, or be caused
by anything in another. A sealed multiverse is just a stack of these lines,
running in parallel, never aware of each other.

```
   THREAD α ──●──●──●──●──●──▶
   THREAD β ──●──●──●──●──●──▶
   THREAD γ ──●──●──●──●──●──▶
            (parallel, sealed — no contact)
```

---

## 2. BRANCHING

A Thread can **branch**: a single decision-point spawns a divergent line that
runs forward on its own. Both halves are real. The branch is *downstream* of a
shared past, so the two Threads agree on everything before the split and nothing
guaranteed after it.

```
                         ┌──●──●──●──▶  THREAD α  (outcome A)
   shared past ──●──●──●─┤
                         └──●──●──●──▶  THREAD α' (outcome B)
                         ▲
                     branch-point
```

Branches are the gentlest kind of divergence: no wall is broken, the multiverse
simply has one more line in it.

---

## 3. THE RIFT (multi-level causality damage)

A **Rift** is damage to the *seal* between Threads — a place where the wall that
keeps causality local fails. Rifts come in **levels**, by how much causality
leaks across:

```
  LEVEL 0 — SEALED      | wall intact. no cross-thread causality.
  ───────────────────────────────────────────────────────────────
  LEVEL 1 — HAIRLINE    | information bleeds. echoes, déjà vu, "ripples."
       α ──●──┊──●──▶     a cause in one Thread is faintly FELT in another.
       β ──●──┊──●──▶
  ───────────────────────────────────────────────────────────────
  LEVEL 2 — SEAM        | matter/energy crosses. a thing in α can ACT in β.
       α ──●──╫──●──▶     an object, a force — or a person — passes through.
       β ──●──╫──●──▶
  ───────────────────────────────────────────────────────────────
  LEVEL 3 — CONVERGENCE | the walls fail together. multiple Threads share
       α ──●──╲            one local causality. an effect HERE can have a
       β ──●───●──●──▶     cause THERE, and the distinction stops mattering.
       γ ──●──╱
```

This is what "**multi-level causality rifts**" means: causality doesn't simply
break or hold — it degrades through stages, and a single region of the multiverse
can carry *different rift levels at once* (a hairline here, a seam there, a full
convergence at the centre).

```
        ┌── LEVEL 1 (ripples) ──┐
   α ───┤                       ├─── LEVEL 3 (convergence) ─── ▶
   β ───┤   LEVEL 2 (a seam)    │
   γ ───┴───────────────────────┘
        the same event-space, layered rift depths
```

---

## 4. CONVERGENCE

**Convergence** is the deep end: two or more Threads bleeding into a shared
present. While it holds, causes and effects cross freely between the joined
Threads — what happens in one is *real* in the others. It is the only state in
which inhabitants of different Threads can stand in the same room, fight the same
fight, and change the same outcome.

```
   THREAD α ──●──●──╲
   THREAD β ──●──●───● CONVERGENCE ●──●──▶   (one shared "now")
   THREAD γ ──●──●──╱
```

Convergence is powerful and **unstable**. Walls that fail together do not
politely stay failed; sealing, re-branching, or a deeper collapse are all on the
table once the threads are touching.

---

## 5. GLOSSARY

| Term | Meaning |
|------|---------|
| **Thread** | one complete, internally-consistent timeline |
| **Sealed** | the normal state: no causality crosses between Threads |
| **Branch** | a Thread splitting into two downstream of a decision-point |
| **Rift** | damage to the seal between Threads (Levels 0–3) |
| **Ripple** (L1) | information/echoes leaking across a hairline rift |
| **Seam** (L2) | matter, energy, or a person crossing between Threads |
| **Convergence** (L3) | walls failed together; Threads share one local causality |
| **Local causality** | cause-and-effect contained within a single Thread |
| **Cross-thread causality** | cause in one Thread, effect in another (rift-enabled) |

change — that is the story, and the story this primer does not tell.*
